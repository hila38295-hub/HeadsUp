# 고개 들어! (HeadsUp)

수업 중 설정한 범위(1~10분) 안에서 **초 단위 랜덤 간격**으로 화면 상단에 배너를 띄워
교수님을 한 번씩 바라보게 해 주는 안드로이드 앱.

## 기능
- 알림 간격: 1분~10분 범위에서 최소/최대를 10초 단위로 지정, 그 사이에서 초 단위 랜덤
- 배너: 다른 앱을 쓰는 중에도 화면 위에 표시 (소리·진동 없음), 탭하면 바로 닫힘
  - 문구 직접 입력 (기본: "교수님을 바라보세요!")
  - 배경색 / 글자색 선택 (기본: 흰 배경 + 검은 글자)
  - 표시 시간 1~10초
- 수업 시간 설정 → 자동 종료 / 끄면 종료할 때까지 계속
- 일시정지 · 재개 · 종료 (앱 화면, 또는 알림창의 무음 상태 알림에서)
- 시작 시간 예약

## 빌드 방법
1. Android Studio에서 `File > Open` → 이 `HeadsUp` 폴더 선택
2. Gradle 동기화가 끝나면 태블릿을 USB(개발자 옵션 → USB 디버깅)로 연결
3. ▶ Run 버튼 → 태블릿에 바로 설치
   - APK 파일만 필요하면 `Build > Build App Bundle(s) / APK(s) > Build APK(s)`
     (`app/build/outputs/apk/debug/app-debug.apk`)

## 처음 실행할 때 켜야 하는 권한
| 권한 | 왜 필요한지 |
|---|---|
| 다른 앱 위에 표시 | 다른 화면을 보고 있어도 배너가 뜨게 (필수) |
| 알람 및 리마인더 | 예약 기능을 쓸 때만 |
| 알림 | 알림창에서 일시정지/종료 버튼을 쓰려면 (거절해도 앱은 동작) |

### 주의
- **APK 파일을 직접 받아 설치한 경우** 안드로이드 13 이상에서는 '다른 앱 위에 표시'가 회색으로
  막혀 있을 수 있어요. `설정 > 애플리케이션 > 고개 들어! > ⋮ (오른쪽 위) > 제한된 설정 허용`을
  먼저 누른 뒤 다시 켜면 됩니다. Android Studio의 Run으로 설치하면 이 문제는 없어요.
- 삼성 태블릿은 배터리 절약 때문에 백그라운드 앱을 끄는 경우가 있어요.
  `설정 > 애플리케이션 > 고개 들어! > 배터리 > 제한 없음`으로 두면 안정적이에요.
- 화면이 꺼져 있는 동안에는 배너를 띄우지 않고 기다리다가, 다시 켜진 뒤 이어서 알려요.
- 태블릿을 재부팅하면 예약은 사라져요.

## 구조
- `MainActivity.kt` — 설정 화면, 시작/일시정지/종료/예약
- `LookUpService.kt` — 포그라운드 서비스: 랜덤 타이머, 자동 종료, 무음 상태 알림
- `BannerOverlay.kt` — 다른 앱 위에 뜨는 배너
- `Reserver.kt` — 예약 시작 (AlarmManager)
- `Prefs.kt` — 설정 저장
